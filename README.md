🤖 Smart Rule-Based Chatbot

📌 Project Overview

This project is a Smart Rule-Based Chatbot developed in Python as Task 1 of the CodSoft Artificial Intelligence Internship.

The chatbot responds to user queries using predefined rules ("if-elif" statements) without using machine learning. It demonstrates the basic concepts of Artificial Intelligence, Natural Language Processing (NLP), and conversation flow.

✨ Features

- 👋 Personalized greeting
- 💬 Rule-based conversation
- 🕒 Current date and time
- 😂 Random jokes
- 💡 Motivational quotes
- 🧮 Built-in calculator
- 📋 Help menu
- 🙏 Thank-you responses
- 👋 Exit command
- ⚠️ Invalid input handling

🛠️ Technologies Used

- Python 3
- datetime module
- random module

🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run:

python chatbot.py
