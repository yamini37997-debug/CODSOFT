 Task 2: 🎮 Tic-Tac-Toe AI using Minimax Algorithm

📌 Project Overview

This project is a Python-based implementation of the classic Tic-Tac-Toe game where a human player competes against an AI opponent. The AI uses the Minimax Algorithm, which evaluates all possible game states to make the optimal move, making it impossible to defeat.

This project demonstrates the application of Artificial Intelligence concepts such as game search, decision-making, and adversarial problem solving.

---

🎯 Objectives

- Develop a playable Tic-Tac-Toe game in Python.
- Implement an unbeatable AI opponent using the Minimax algorithm.
- Understand game state evaluation and recursive search techniques.
- Demonstrate AI decision-making in a two-player game.

---

✨ Features

- Human vs AI gameplay
- Unbeatable AI using the Minimax algorithm
- Automatic winner and tie detection
- Simple command-line interface
- Clean and modular Python code
- No external libraries required

---

🧠 AI Algorithm

The AI is powered by the Minimax Algorithm, which works by:

1. Exploring every possible future move.
2. Simulating both the human and AI turns.
3. Assigning scores to game outcomes.
4. Selecting the move that guarantees the best possible result.

Scoring:

- AI Win (O): +1
- Human Win (X): -1
- Draw: 0

---

🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Enum Module
- Minimax Algorithm

The Movie Recommendation System is a simple Java console application that recommends movies based on the user's preferred genre. It demonstrates the fundamentals of object-oriented programming (OOP) by organizing movie data into classes and filtering recommendations according to user input.

This project was developed as part of my AI/Java internship to strengthen my understanding of Java programming, collections, and basic recommendation logic.

---

- Predefined movie dataset.
